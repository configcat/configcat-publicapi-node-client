# EvaluationVersion

Determines the evaluation version of a Config. Using `v2` enables the new features of Config V2 (https://configcat.com/docs/advanced/config-v2).

## Enum

* `V1` (value: `'v1'`)

* `V2` (value: `'v2'`)
